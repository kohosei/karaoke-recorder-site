# karaoke-recorder-site

Karaoke Recorder の公開ページ（紹介・プライバシーポリシー・利用規約）。GitHub Pages で https://kohosei.github.io/karaoke-recorder-site/ に出す。

Google Cloud の OAuth 同意画面（ブランディング）がこの URL を参照している。**消すと同期の公開ステータスに影響する。**

アプリの挙動（扱う情報、Google ドライブへのアクセスのしかた、通信先）を変えたときは、`privacy.html` も合わせて直すこと。アプリ本体は隣のフォルダ `../karaoke-recorder`。
